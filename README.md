# Smart Industrial Safety Monitoring System Using LPC2129

## 📌 Project Overview

The Smart Industrial Safety Monitoring System is an embedded systems project developed using the LPC2129 ARM7 microcontroller. The system is designed to monitor industrial working conditions using multiple sensors and identify potentially hazardous situations.

It continuously collects sensor data, processes the readings, and provides alerts when abnormal conditions are detected. This system helps improve workplace safety by enabling real-time monitoring of industrial environments.

## 🎯 Objectives

- Monitor industrial environmental conditions in real time.
- Interface multiple sensors with the LPC2129 microcontroller.
- Detect hazardous conditions using sensor readings.
- Generate alerts when sensor values exceed predefined thresholds.
- Improve industrial safety through automated monitoring.

## 🛠️ Hardware Requirements

- LPC2129 ARM7 Microcontroller
- Temperature Sensor
- Gas Sensor
- Smoke Sensor
- Flame Sensor
- Buzzer
- LCD Display
- LED Indicators
- Power Supply

## 💻 Software Requirements

- Keil µVision IDE
- Embedded C Programming
- Proteus Design Suite
- Flash Magic

## ⚙️ Working Principle

1. Initialize the LPC2129 microcontroller and its peripherals.
2. Configure GPIO pins for sensor interfacing.
3. Configure ADC channels to read analog sensor values.
4. Continuously collect data from the connected sensors.
5. Compare sensor readings with predefined safety thresholds.
6. If hazardous conditions are detected, activate the buzzer and LED indicators.
7. Display sensor readings and safety status on the LCD.
8. Continue monitoring the industrial environment.
